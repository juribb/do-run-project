06 비즈니스 모델

비즈니스 모델 가설

사용자 가치 — 익숙하지 않은 지역에서 적합한 코스를 선택한다.

제휴 접점 (수익모델 가설)

러닝 브랜드 광고·제휴

러닝화·의류·용품 콘텐츠, 코스 연계 캠페인, 제휴 링크

지역 기반 제휴

러닝 스테이션·카페·숙소·샤워시설 등 코스 주변 장소

확장 검토

지역 러닝 이벤트·대회와의 콘텐츠·프로모션 연결

수익 구조 (가설)

사용자에게 직접 과금하지 않으면서, 러닝이라는 명확한 관심사와 지역 기반 이용 상황을 관련 브랜드·지역 서비스와 연결할 수 있을 것으로 기대한다.

과금 단위·단가·제휴 계약·매출은 아직 제시되지 않음.

비용 구조

지도·경로 API · 데이터 처리 · 서버·인프라 · 개발·운영
